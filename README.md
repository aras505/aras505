**Kiori** is memory for character AI. It builds each character's brain from their card, learns from the chat as it happens, and right before every reply hands your model exactly what that character knows: what they lived, who they love, what they never saw and what they hide. It stores no brains and no chats; the brain stays with you.

- 🧠 An API with JavaScript and Python SDKs, an OpenAI-compatible drop-in and a SillyTavern extension
- 🔒 One Node process, zero dependencies, model keys sealed, nothing kept
- 🌸 In private beta, free while it lasts: [ask for access](https://kiori.io/#access)
